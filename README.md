# Школа амбассадоров ТАРКОС — прототип

MVP корпоративной школы: лендинг, личный кабинет участника, кабинет администратора
и 49 анимированных уроков-презентаций.

- `out/site.html` — сайт (лендинг + кабинеты)
- `out/blockN/*.show.html` — уроки, режим показа
- `out/int/*.show.html` — интерактивы блоков

Прототип без бэкенда: данные участников, расписание и переписка — демонстрационные.
